# India reference profile

Based on the 306-record tracked India snapshot. `MorningConsult`,
`ITG-KI MOTN PM`, and `ITG-CVoter PM` are existing PM-approval/performance
series. Their `GOV` variants are out of scope. `IPSOS` requires explicit
PM-approval wording. `GALLUPWORLD_LSHP` and `GALLUPWORLD_LDR` require
REVIEW because generic leadership wording need not name the Prime Minister.
`PRC-PMSupport` and `LOKNITI CSDS PM LIKE` are out of scope as
favorability/likeability measures. Use the reference index before staging.

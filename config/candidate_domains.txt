# Pollitik Database — Candidate/Discovery-Tier Domains (NOT enforced)

# THIS FILE IS NOT READ BY .claude/hooks/pollitik_guard.py OR
# python/pollitik_common.read_allowed_domains(). Nothing here grants
# WebFetch access. It exists so a large batch of discovered domains can
# be preserved and reviewed without being treated as approved merely by
# being present — the mistake this file exists to prevent (see the
# provenance note below).
#
# RELATIONSHIP TO config/allowed_domains.txt:
#   config/allowed_domains.txt  = the ONLY enforced allow-list.
#   config/candidate_domains.txt (this file) = discovery-tier only. A
#     domain here has NOT been explicitly approved by the project owner
#     and must not be WebFetched. `python/check_domain.py` only checks
#     config/allowed_domains.txt - being listed here does not make
#     `check_domain.py` report APPROVED.
#
# PROMOTION: moving a specific domain from this file to
# config/allowed_domains.txt requires the project owner's explicit,
# per-domain (or explicit-batch) approval - the same standard
# config/allowed_domains.txt's own rule 4/5 has always required. Do not
# promote a domain from this list without that approval, regardless of
# how it was originally derived.
#
# --------------------------------------------------------------------
# PROVENANCE / WHY THIS FILE EXISTS
#
# On 2026-08-13, PR #1 (sushmitha/canada-pm-assignment1) added the 381
# domains below directly into config/allowed_domains.txt - the
# enforcement file - under a comment describing "Professor Ryan's
# Assignment 1 rule": every unique valid domain associated with a
# Master-sheet data point dated 2024-01-01 or later in
# data/master/pollitik_master.xlsx, derived by deterministic bulk
# extraction (not per-domain review).
#
# That made all 381 domains live, WebFetch-approved sources - globally,
# for every country's research, not just Canada's - even though:
#   - the large majority are not Canada-related at all (the whole
#     workbook spans many countries, so its Source column does too);
#   - bulk "every domain the workbook has ever cited" is a materially
#     weaker/different standard than config/allowed_domains.txt's own
#     documented rule ("explicitly approved by the project owner ... one
#     at a time or as an explicit batch") - a classroom assignment rule
#     is not the project owner approving a specific source;
#   - none of the 381 were individually vetted for authenticity,
#     continued legitimacy, or relevance to any specific research task.
#
# Per the project owner's instruction, this data is preserved (not
# deleted) but moved here, out of the enforcement path, and reclassified
# as discovery/candidate-tier pending real per-domain review. No domain
